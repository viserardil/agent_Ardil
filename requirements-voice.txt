# Kurulum (OneDrive'da hardlink hatası olmaması için --link-mode=copy şart):
#
#   1) CUDA'lı torch (RTX serisi için cu124 index'inden):
#      uv pip install --link-mode=copy torch==2.6.0 torchaudio==2.6.0 \
#          --index-url https://download.pytorch.org/whl/cu124
#
#   2) Kalan ses bağımlılıkları (bu dosya):
#      uv pip install --link-mode=copy -r requirements-voice.txt
#
#   3) FreyaTTS bir pip paketi DEĞİL — klonlanıp PYTHONPATH'e eklenir:
#      git clone --depth 1 https://github.com/freyavoiceai/FreyaTTS vendor/FreyaTTS
#      export PYTHONPATH=vendor/FreyaTTS   (Windows: set PYTHONPATH=vendor\FreyaTTS)
#      Model ağırlıkları: https://huggingface.co/freyavoice/Freya-TTS
#
# NOT: torchaudio, torch ile AYNI sürüm/derleme olmalı (2.6.0+cu124). voxcpm
# uyumsuz bir torchaudio (2.11) çekmeye çalışırsa yukarıdaki komutla sabitleyin.
# ============================================================================
